# Aviva Fuller · Personal website

Portfolio site for Aviva Fuller, Statistics PhD student at Rutgers. Plain HTML/CSS/JS, no build step, hosted on GitHub Pages.

- `index.html`: content (edit text here)
- `style.css`: design tokens and layout (light + dark mode)
- `script.js`: the Galton board animation, nav highlighting, scroll reveals

To preview locally, open `index.html` in a browser or run `python3 -m http.server`.
