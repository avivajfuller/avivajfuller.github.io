Projects

Handling Missing Labels in Linear Discriminant Analysis

Rutgers University

Spring 2026

  • R
  • Classification
  • Missing data
  • Simulation study

Extended Weighted Missing LDA (Vo et al., 2024) to training data with missing class labels. My method pseudo-labels unlabeled rows, then down-weights them in the class priors by the model's estimated per-class accuracy. I compared it with complete-case WLDA on three datasets at missing rates up to 75%.

Code and write-up on GitHub →
